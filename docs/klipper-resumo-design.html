Resumo de arquitetura & produto

Klipper — Wealth Operating System

Sistema pessoal de gestão financeira: contas, transações, orçamento, investimentos e um copiloto de IA (Kira). Este documento consolida arquitetura, decisões técnicas, inventário de telas, sistema de design e padrões de interação para handoff com o coordenador de design.

Repo · github.com/Borussia80/Klipper Monorepo · 3 apps Telas ativas · 11 Stack atual · Nuxt 4 + Rails 8
01 — visão geral

Arquitetura

Klipper é um monorepo com três aplicações independentes. O produto principal é um PWA (app instalável, funciona offline-first) servido separadamente da API de domínio — não há SSR acoplado ao backend de negócio.

klipper-web

Nuxt 4 (Vue 3) · PWA · frontend do app financeiro. 11 rotas ativas, componentes em Vue SFC.

klipper-api

Rails 8 API-only · PostgreSQL · JWT auth · domínio de contas, transações, orçamento e investimentos.

quebec-web

Nuxt 4 · landing institucional da Quebec (empresa-mãe do produto), separada do app logado.

02 — histórico

Decisões de arquitetura

O produto passou por três reescritas de stack em poucos meses. Cada uma teve motivo específico — importante para não propor voltar a padrões já descartados.

até jun/2026
Streamlit (Python)
Protótipo original. Multi-page app com st.dialog para modais. Descartado: limitações de UI/mobile e de customização de interação.
jun/2026
Next.js 16 + React 19 (PWA) na Vercel
Primeira reescrita como PWA de verdade (Serwist, ícones, auth via Supabase). Descartada em favor de Vue/Nuxt por preferência de stack do time.
21/jun/2026 → atual
Nuxt 4 (frontend) + Rails 8 (backend)
Decisão vigente. Frontend em Vue/Nuxt, domínio de negócio concentrado em Rails (auth, jobs, cache, filas). React mantido apenas como ilha isolada para os gráficos (Recharts).
06/jul/2026
Deploy da API migra para Render
Configuração Kamal/Render substitui a tentativa anterior via Railway/Vercel serverless para a API.

04 — sistema de design

Design system

Tema único, dark-first (não há light mode implementado no produto ainda). Paleta fria, construída para leitura de números financeiros por longos períodos — contraste é tratado como requisito, não afterthought: os tokens de texto já vêm anotados com a razão de contraste WCAG contra o fundo.

Instituições financeiras (cores de marca)

Bancos recebem cor própria e reconhecível — Nubank #8A05BE, Itaú #EC7000, BTG #0B2545 — mais cripto #F4C030. Novos bancos/ativos precisam de um token de cor equivalente antes de entrar em produção.

Tipografia

Números e labels técnicos usam monospace (JetBrains Mono) com tabular-nums — visível em rótulos de step ("Passo 1 de 3"), badges BETA e valores monetários. Texto de interface usa a fonte do sistema. Não há uma família serifada no produto.

Layout & responsividade

Três colunas no desktop: sidebar fixa (--nav: 228px) · conteúdo · painel direito contextual (--rp: 284px, muda de conteúdo conforme a página — patrimônio no Dashboard, resumo de categoria em Transações etc). Em mobile, sidebar e painel direito somem; surge bottom-nav fixo com os mesmos 6 itens principais. Raio de borda padrão é discreto (--r: 6px).

05 — padrão de interação

Modais

Não são modais centrais — é um drawer lateral (slide-in pela direita, 420px, full-screen em mobile), compartilhando um único componente-base (BaseModal) com focus-trap, fechamento por Esc, aria-modal e devolução de foco ao elemento que abriu o painel. Todas as 4 telas de criação usam esse mesmo padrão — decisão deliberada de consistência, não uma coincidência de implementação.

06 — feature destaque

Kira — copiloto financeiro

Chat de IA dedicado (rota própria, não um widget flutuante), marcado como beta. Estado vazio traz avatar animado e 4 chips de sugestão que cobrem as perguntas mais prováveis de um usuário novo:

"Qual é meu saldo atual?" "Onde gastei mais este mês?" "Quanto tenho em investimentos?" "Estou dentro do orçamento?"

Visualmente diferenciada do resto do produto pelo tom roxo (--pur #7C5CF5) — único lugar da interface que usa essa cor, o que a torna reconhecível como "zona de IA" em qualquer tela.
